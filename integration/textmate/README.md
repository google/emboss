# TextMate Grammar for Emboss

This directory contains the TextMate grammar (`emboss.tmLanguage.json`) for the Emboss language.

It provides syntax highlighting for tools that support TextMate grammars, such as:
- VS Code (via extensions)
- GitHub (via Linguist)
- Sublime Text

To add Emboss syntax highlighting to GitHub, this file can be used by GitHub's [Linguist](https://github.com/github-linguist/linguist) library.
